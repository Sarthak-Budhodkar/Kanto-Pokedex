# Kanto Pokédex

A web-based Pokédex for Generation 1 Pokémon.

## Overview
This project brings the original Kanto region Pokémon to the browser. It provides a quick way to browse Pokémon, look up details, and explore the first-generation roster.

## Features
- Search Pokémon by name or number
- View basic information for each Pokémon
- See stats and type details
- Browse the Gen 1 Pokédex collection
- Simple, responsive interface

## Tech Stack
- JavaScript
- CSS
- HTML

## Run Locally
1. Clone the repository:
   ```bash
   git clone https://github.com/Sarthak-Budhodkar/Kanto-Pokedex.git
   ```
2. Open the project folder.
3. Launch `index.html` directly in a browser, or run a local server:
   ```bash
   python -m http.server 8000
   ```
4. Visit `http://localhost:8000`.
